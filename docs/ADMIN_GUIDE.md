# Как управлять сайтом — инструкция для заказчика

Всё содержимое сайта меняется в админке без программиста. Сайт для туристов — на английском,
админка — на русском.

**Вход:** `https://ваш-домен/<адрес админки>` (адрес даст разработчик). После 5 неверных паролей
вход блокируется на 1 час — это защита от взлома.

---

## 1. Первым делом: настройки сайта

Меню слева → **Настройки → Контакты и SEO**. Вкладки:

| Вкладка | Что заполнить |
|---|---|
| Компания | Название, слоган, адрес |
| Главная | Заголовок и подзаголовок первого экрана, фото, тексты «Private / Group tours», тексты блока «О нас» (надпись над заголовком, заголовок, текст, подпись ссылки) |
| Контакты | Телефон, **WhatsApp** (только цифры с кодом страны: `996555123456`), Telegram (без @), **почта для заявок** |
| Соцсети | Ссылки на Instagram, TikTok, Facebook, TripAdvisor, YouTube — в подвале появятся круглые иконки рядом с WhatsApp. Пустое поле — иконки нет |
| Карта | 3D-рельеф: «Везде», «Только компьютеры» или «Выключен» (если на телефонах тормозит) |
| Правовое | Политика конфиденциальности — заполнить поля в [квадратных скобках] |
| SEO и аналитика | Заголовок и описание для Google, картинка для превью, **ID Google Analytics** (`G-...`) |

**Выделение в заголовках:** часть текста в `*звёздочках*` станет оранжевой.
Пример: `Mountains, lakes *and yurts*`.

### Блок «О нас»: фото вокруг текста

Меню слева → **Контент → Фото «О нас»**. Вокруг текста на главной «плавают» до **7 фото** — порядок
меняется перетаскиванием (первое — слева вверху, дальше по кругу). Хорошо смотрятся вперемешку:
3 портрета гидов и 4 места (озёра, юрты, горы). В поле **«подпись на фото»** можно написать имя
гида — оно появится на фото. Пока сюда ничего не загружено, сайт сам берёт фото «О нас», гидов
и обложки туров. Цифры под текстом — в **Контент → Счётчики**.

### Блок «Основатель»

Та же вкладка **Главная**: имя, роль, год основания, фото, цитата, история. В поле
**«Instagram основателя»** вставьте ссылку на личный профиль (`https://instagram.com/...`) —
рядом с именем появится круглая иконка Instagram. Пустое поле — иконки нет.

### Фото в блоке отзывов

Фон за отзывом на главной — **главное фото того тура**, о котором отзыв. Листаете отзывы —
меняется и фото. Чтобы поменять фон, смените главное фото тура или тур в самом отзыве.

## 2. Как добавить тур

**Туры → кнопка «+»** (справа вверху). Вкладки:

1. **Основное** — название, адрес страницы (заполнится сам), тип (одиночный / групповой),
   главное фото, строка «Расписание» (сколько выездов и ссылки на них), краткое и полное описание,
   «как добраться» (каждая строка — отдельный пункт), галочки «показывать на сайте» и «хит сезона».
2. **Цена и параметры** — цена от, валюта, пояснение (`per person`), дни, сложность, размер группы,
   сезон.
3. **SEO** — можно не трогать: если пусто, берутся название и краткое описание.
4. **Дни маршрута** — добавить дни: номер, заголовок, описание, расстояние, набор высоты,
   время в пути, ночёвка. Точки на карте — см. раздел 3.
5. **Галерея** — фото тура, порядок меняется перетаскиванием.
6. **Включено / не включено / снаряжение** — списки для вкладок на странице тура.

Нажмите **«Сохранить»**. Пока галочка «показывать на сайте» снята, тур видит только админ
(кнопка «Смотреть на сайте» вверху формы).

**Фото:** загружайте как есть, сайт сам сделает лёгкие копии для телефонов. Лучше горизонтальные,
от 1600 px по ширине. Только свои фото или с разрешённой лицензией.

**«Хит сезона»** — такие туры попадают в карусель на главной.
**Порядок туров** — перетаскивайте строки за значок ⋮⋮ слева в списке туров.

### Даты выездов (расписание)

На странице тура туристы видят ленту карточек с датами, местами и ценой и нажимают «Choose» —
дата сама попадает в заявку. Все даты всех туров — на странице **Tour dates**.

**Запланировать сразу сезон:** меню слева → **Туры → Расписание выездов** → кнопка
**«Запланировать даты»** (или ссылка «Запланировать даты» в строке «Расписание» внутри тура).

1. Выберите тур, **первый выезд** (календарик) и **как часто**: каждую неделю, раз в 10 дней, раз в
   2 недели… или «только эту дату».
2. **До какой даты** — можно не заполнять (год вперёд). Даты вне сезона тура пропускаются сами.
3. **Мест в группе** — пусто: возьмётся «группа до» из тура.
4. Нажмите **«Показать даты»** — появится список всех дат с днями недели. Проверьте и нажмите
   **«Создать»**. Уже существующие даты не дублируются.

**Менять потом — прямо в списке расписания:** поправьте «осталось мест», цену или пометку
(например `Festival week`) и нажмите «Сохранить» внизу. Поставили **0 мест** — на сайте будет
«Sold out», вернули места — дата снова открыта. Дата окончания считается сама по длительности тура.

**Полезное:** фильтр «когда» (предстоящие / прошедшие), фильтр по туру, действие
**«Скопировать на следующий год»** — выделите даты галочками, выберите действие, и они
повторятся через год в тот же день недели. Удалить дату — галочка → «Удалить».

Если у тура нет дат: у **частного** тура на сайте будет «you choose the dates», у **группового** —
текст из поля «ближайший выезд» (например `Any day, May – October`).

## 3. Маршрут дня на карте

В туре на вкладке «Дни маршрута» нажмите на день (или **Туры → Дни маршрутов**). Внизу — карта.

1. **Кликайте по карте** — каждая точка получает номер. Порядок точек = порядок маршрута.
   Точки можно перетаскивать, переименовывать, менять местами (↑ ↓) и удалять (✕).
   Кнопка «Topo» показывает тропы и перевалы.
2. Выберите, **как соединить точки**:
   - **Прямые линии между точками** — просто и всегда работает;
   - **По дорогам (машина)** — для дней с переездом;
   - **По пешим тропам** — линия пойдёт по тропе. Если сервис не нашёл тропу, придвиньте точки
     ближе к пунктирной тропе на слое «Topo»;
   - **Из GPX-трека** — загрузите файл с часов или телефона гида (самый точный вариант).
3. **«Построить линию»** — предварительный просмотр. **«Сохранить»** — линия появится на сайте.

Расстояние и набор высоты заполнятся сами, если поля пустые.

## 4. Заявки

Каждая заявка приходит **на почту** (на русском) и сохраняется в **Заявки → Заявки с сайта**.
Число новых заявок видно в меню слева.

- В письме нажмите **«Ответить»** — ответ уйдёт туристу. Если турист оставил номер, в письме есть
  ссылка на WhatsApp.
- В админке отмечайте статус: **Новая → В работе → Обработана**. Спам можно пометить.
- Внизу заявки — техническая информация: с какой страницы и из какой рекламы пришёл турист.

---

## 5. Остальной контент

Меню **Контент**: гиды, отзывы, частые вопросы, партнёры, «живые кадры» (фото для блока
соцсетей), счётчики («12+ years in the mountains»).

- Порядок — перетаскиванием, видимость — переключателем «показывать на сайте».
- **Если раздел пустой, блок на сайте просто не показывается.**
- Отзывы публикуйте только настоящие, с разрешения туриста.

---

## 6. Если что-то пошло не так

- Опечатка или неверная цена — исправьте и сохраните, сайт обновится сразу.
- Удалили что-то по ошибке — у каждого объекта есть «История» (кнопка вверху формы);
  данные целиком восстанавливаются из ежедневного бэкапа (обратитесь к разработчику).
- Письма не приходят — проверьте папку «Спам» и «почту для заявок» в настройках.
